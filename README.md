# WORLDSHIFT — TERRA

لعبة بناء ومحاكاة ثلاثية الأبعاد تعمل في المتصفح، على الموبايل والكمبيوتر، من غير تثبيت ومن غير حساب.

**العب الآن:** https://amohamedfgdfdt-ctrl.github.io/worldshift/

ابنِ مدينتك فوق عالم حي فيه جبال ونهر وبحيرة، وراقب الماء وهو يجري ويتجمع ويحيط بالمباني، ويتحول النهار إلى ليل.

## كيف تلعب

1. **اختر فئة** من الشريط الجانبي: المباني، الطبيعة، البنية التحتية، أدوات المياه، إعدادات العالم.
2. **اختر عنصراً** (منزل، مصنع، مزرعة، شجرة، طريق، خزان مياه…).
3. **حرّك المعاينة الشفافة** فوق الأرض: الأخضر يعني أن المكان صالح، والأحمر يعني أنه غير صالح (ويظهر السبب).
4. **ثبّت** بالضغط أو بزر ✓.
5. **اضغط على أي مبنى** لتشاهد معلوماته أو لحذفه.

### أفكار للعب
- ابنِ منازل في الأراضي المرتفعة وراقب السكان وهم يسكنونها.
- ضع مزرعة قرب الماء لتحصل على ري أفضل.
- ضع خزان مياه ليسحب الماء من حوله ويحمي المنطقة.
- أضف مصدر مياه أو أمطاراً وشاهد كيف يلتف الماء حول المباني، وإن غمرها غادرها سكانها.

## التحكم

| | الموبايل | الكمبيوتر |
|---|---|---|
| تدوير الكاميرا | إصبع واحد | السحب بالزر الأيسر |
| تحريك الكاميرا | إصبعان، أو الزر الجانبي | الزر الأيمن، أو WASD |
| تقريب وتبعيد | قرص بإصبعين | عجلة الماوس |
| تشغيل وإيقاف | زر ▶ / ⏸ | Space |
| إلغاء | زر ✕ | Esc |

على الموبايل: اضغط مطولاً بأداة «إضافة ماء» لصب الماء.

## الوقت والسرعة

من الشريط السفلي: تشغيل وإيقاف، وسرعة ×1 أو ×2 أو ×4، وإعادة ضبط الماء والساعة (مبانيك تبقى). عند الإيقاف تتوقف المياه والرياح والسكان، وتبقى الكاميرا والبناء يعملان.

## الأداء والإعدادات

إذا كانت اللعبة بطيئة على جهازك، افتح **إعدادات العالم** (⚙️):

- **جودة الرسوميات:** تلقائي (تخفض الدقة وحدها عند الحاجة)، أو عالية، متوسطة، منخفضة.
- **سقف الفريمات:** 60 أو 30 أو بدون حد. السقف الأقل يوفّر البطارية.
- **اللغة:** العربية أو English.

## الحفظ

تُحفظ مدينتك **تلقائياً** على جهازك كل بضع ثوانٍ، وتعود إليها عند فتح اللعبة من جديد. يمكنك أيضاً **حفظ** و**تحميل** و**عالم جديد** (الوادي الكلاسيكي أو عالم عشوائي) من إعدادات العالم.

> الحفظ داخل المتصفح نفسه: لا ينتقل بين الأجهزة، وقد يُمسح إذا حذفت بيانات الموقع أو لعبت في الوضع الخاص.

## أسئلة شائعة

**شاشة سوداء أو رسالة WebGL؟** استخدم نسخة حديثة من Chrome أو Safari أو Firefox أو Edge.

**لا أستطيع البناء في مكان معيّن؟** ستظهر رسالة بالسبب: ماء، أو انحدار شديد، أو مكان مشغول، أو خارج الخريطة.

**اختفت مدينتي؟** غالباً مُسحت بيانات المتصفح. استخدم الرابط نفسه والمتصفح نفسه دائماً.
