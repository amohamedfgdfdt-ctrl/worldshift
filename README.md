# TERRA — Living World Simulator (المرحلة 1)

عالم ثلاثي الأبعاد بتضاريس ونهر وبحيرة وأشجار وسماء، مع محاكاة مياه تفاعلية وكاميرا تعمل باللمس.

## التشغيل على كمبيوتر
```
python3 -m http.server 8080
```
ثم افتح http://localhost:8080 (لازم إنترنت لتحميل Three.js من CDN).

## النشر على GitHub Pages من الهاتف
1. ارفع محتويات مجلد TERRA في repository (بنفس طريقة Codespaces: ارفع الـ ZIP، فك الضغط، ثم `git add . && git commit -m "TERRA" && git push`).
2. من Settings ← Pages: اختر Source = Deploy from a branch، الفرع main والمجلد / (root).
3. بعد دقيقة افتح https://USERNAME.github.io/REPO/

## الهيكل
- `js/terrain.js`: التضاريس والألوان والأشجار (InstancedMesh)
- `js/water-system.js`: محاكاة المياه على شبكة 96×96
- `js/simulation.js`: التشغيل والإيقاف والسرعة
- `js/camera.js` / `js/world.js` / `js/ui.js` / `js/main.js`

## المنفّذ في هذه المرحلة
تضاريس وجبال ووديان، نهر وبحيرة، مياه تتدفق وتتجمع في المنخفضات، مصدر مياه (تشغيل/إيقاف/قوة)، سرعة التدفق، أمطار، Play/Pause وسرعات ×1 ×2 ×4، إعادة المياه، كاميرا (دوران وتقريب وإعادة بانتقال سلس)، ظلال وسماء وسحب.

## القيود
- الألوان إجرائية (بدون صور خامات) والمياه محاكاة مبسطة وليست فيزياء موائع دقيقة.
- لا يوجد بناء ولا حفظ بعد (المرحلتان 2 و3). الأشجار لا تتحرك مع الرياح.
- لم أستطع تشغيله على جهاز حقيقي أثناء الكتابة، فالأداء على هاتفك يحتاج تجربتك.
