# WORLDSHIFT — TERRA · Living World Simulator (Phase 1)

لعبة محاكاة عالم ثلاثية الأبعاد تعمل بالكامل داخل المتصفح (Three.js r170، بدون أي خدمات خارجية أو API Keys).
مكتبة Three.js موجودة داخل المشروع في `vendor/` لذلك **لا يلزم إنترنت** بعد تحميل الصفحة.

## التشغيل محلياً

يجب فتح المشروع عبر خادم (لأن ES Modules لا تعمل من `file://`):

```bash
cd TERRA
python3 -m http.server 8000     # أو: npx serve
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (Public).
2. ارفع **محتويات** مجلد `TERRA` (وليس المجلد نفسه) بحيث يكون `index.html` في جذر المستودع، مع المجلدات `js/` و `vendor/` و `assets/` وملف `.nojekyll`.
3. من المستودع: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. بعد دقيقة تقريباً يظهر الرابط: `https://USERNAME.github.io/REPO/`.

جميع المسارات نسبية، لذلك تعمل اللعبة سواء كانت في جذر الموقع أو داخل مسار فرعي.

### من الهاتف

- **الأسهل (Android/iOS):** فعّل «Desktop site» في المتصفح ثم افتح github.com. زر **Add file → Upload files** على الهاتف يختار *ملفات* وليس مجلدات، لذلك ارفع كل مجلد على حدة: أنشئ المسار بالزر **Create new file** واكتب اسماً مثل `js/main.js` (الشرطة المائلة تنشئ المجلد) ثم استخدم **Upload files** داخل ذلك المجلد لبقية الملفات.
- **بديل أسرع:** تطبيقات Git على الهاتف (Working Copy على iOS، أو Termux على Android) تسمح بفك الـ ZIP ثم `git add . && git commit && git push` دفعة واحدة.
- ملف `vendor/three.module.min.js` حجمه نحو 700 KB، ويقبله GitHub بلا مشاكل.

## طريقة اللعب

| الإجراء | الكمبيوتر | الموبايل |
|---|---|---|
| تدوير الكاميرا | سحب بالزر الأيسر | إصبع واحد |
| تحريك الكاميرا | سحب بالزر الأيمن / Shift+سحب / WASD | الزر الجانبي ⟳/✥ ثم إصبع واحد، أو إصبعان |
| تقريب/تبعيد | عجلة الماوس / + − | قرص بإصبعين / أزرار + − |
| دوران حاد | Q / E | أزرار الدوران، أو لف إصبعين |
| بناء | اختر من القائمة ← انقر لتثبيت (Esc للإلغاء، R للتدوير) | اختر ← المس لتحريك الشفاف ← المس نفس المكان أو ✓ لتثبيت |
| تحديد | انقر على مبنى/طريق/مصدر/ماء/أرض | المس |
| حذف | زر Delete في لوحة المعلومات (أو مفتاح Delete) | زر Delete |
| إضافة ماء | أداة Add Water: اضغط مطولاً بالزر الأيسر | اضغط مطولاً |
| تشغيل/إيقاف | Space | زر ▶/⏸ |

- **الطرق:** انقر لبدء الطريق ثم انقر مرة أخرى لرسم قطعة مستقيمة (على شكل L)؛ تستمر السلسلة حتى Esc.
- **المياه:** تتحرك من الأعلى للأسفل، تتجمع في المنخفضات، وتدور حول المباني (المباني تعمل كعوائق). **خزان المياه** يسحب المياه حوله ويخزنها. **مصدر المياه** يضخ مياهاً بمعدل قابل للتعديل (اضغط عليه في وضع التحديد).
- **السكان:** يبدأون من 0 ويسكنون المنازل تدريجياً أثناء تشغيل المحاكاة، ويغادرون إن غمرتها المياه.
- **الحفظ:** تلقائي كل 10 ثوانٍ وعند أي تغيير وعند إغلاق الصفحة (LocalStorage). أزرار Save / Load / New World في لوحة **World**.

## ما تم تنفيذه واختباره (فعلياً في متصفح Chrome آلي)

- عالم 384×384 م: جبال بثلوج، تلال، سهول، بحيرة، نهر متعرج ينحدر من الجبال إلى حافة الخريطة، أشجار (~900)، شجيرات، صخور، عشب وأزهار، سماء وسحب متحركة، شمس/قمر ونجوم، دورة نهار/ليل، ظلال ناعمة.
- الكاميرا: تدوير، تحريك، تقريب، دوران 45°، تغيير الميلان، إعادة الضبط بحركة سلسة؛ لمس بإصبع وإصبعين (اختُبر بأحداث لمس حقيقية).
- البناء: 7 أنواع (منزل صغير/متوسط، مصنع، شجرة، مزرعة، طريق، خزان) — معاينة شفافة خضراء/حمراء مع سبب الرفض، شبكة تظهر عند البناء وتلوّن الخلايا الصالحة، تثبيت بأثر بصري وحركة، إلغاء، تحديد، لوحة معلومات، حذف.
- المياه: محاكاة شبكة ارتفاعات (virtual pipes): جريان من الأعلى للأسفل، تجمع في المنخفضات، انتشار تدريجي، مصادر مياه، صب وتصريف يدوي، إيقاف المصادر، تغيير سرعة الجريان وقوة المصادر، تصادم مع المباني.
- شريط الوقت: Play / Pause / ×1 / ×2 / ×4 / Reset؛ عند الإيقاف تتوقف المياه والرياح والسكان والوقت مع بقاء الكاميرا والبناء يعملان.
- الحفظ: مواقع وأنواع المباني، الطرق، المصادر، حالة المياه، السرعة، الوقت والإعدادات تُستعاد بعد إعادة تحميل الصفحة؛ New World يعيد توليد عالم جديد.
- الواجهة: Dark premium، تخطيط مختلف للموبايل (قائمة سفلية وأوراق منزلقة) وليس نسخة مصغرة من الكمبيوتر.
- الأداء: InstancedMesh لكل ما يتكرر (≈ 20 Draw Call)، دمج نماذج المباني بتلوين رؤوس، خفض دقة تلقائي (Auto)، ثلاث درجات جودة.

## القيود الحالية (بصراحة)

- **المياه ليست دقيقة علمياً**: نموذج «أنابيب افتراضية» مستقر وجذاب بصرياً؛ لا يحاكي الاضطراب أو الانكسار أو الجرف.
- **لم تُستخدم Rapier**: لا توجد أجسام صلبة في هذه المرحلة، فإضافتها كانت ستزيد الحجم بلا فائدة. سنضيفها عند الحاجة (انهيارات، مركبات).
- **الواجهة بالإنجليزية فقط** (حسب المواصفات)، لا يوجد تبديل لغة بعد.
- **التضاريس ثابتة**: لا يوجد تسوية/حفر. المباني على المنحدرات تستخدم أساسات (حد أقصى للميل لكل نوع).
- **الأشجار/العشب الطبيعي غير قابل للتحديد**، وتُزال تلقائياً من مكان أي بناء جديد (وتعود عند إعادة توليد العالم لا عند الحذف).
- **الاختبار تم على Chrome بمعالج رسوم برمجي (SwiftShader)**، لا على هواتف حقيقية؛ أرقام الإطارات الفعلية ستختلف. وضع Auto مصمم لخفض الدقة تلقائياً عند الحاجة.
- لا مزامنة سحابية للحفظ (LocalStorage لكل متصفح، وقد يُمسح في الوضع الخاص).
- الوظائف/الاقتصاد من المراحل القادمة (المصنع يدخّن بصريًا فقط).

كل نظام منفصل: السكان والاقتصاد → `simulation.js` + سجل المباني `buildings.js`؛ الكوارث → `world.js`/`water-system.js` (خطوة المحاكاة تقبل مصادر ومصارف جاهزة)؛ فيزياء متقدمة → وحدة جديدة تُنشأ في `world.js`؛ تحرير التضاريس → `HeightField.h` ثم `TerrainMesh.refresh()` و`WaterSim.syncGround()`.

# المرحلة 3 — الحملة (Campaign) ووضع اللعب الحر (Sandbox)

عند فتح اللعبة تظهر شاشة **اختيار الوضع**، ويمكنك التبديل في أي وقت من زر الوضع (**Campaign / Sandbox**) في الشريط العلوي. زر **العربية / English** بجانبه يبدّل اللغة والاتجاه (RTL/LTR) ويُحفظ اختيارك.

## الوضعان

| | Sandbox (لعب حر) | Campaign (حملة) |
|---|---|---|
| القيود | لا شيء: كل المباني والأدوات متاحة بلا تكلفة | مجموعة أدوات محدودة تتوسع بمكافآت المراحل |
| الاقتصاد | يُحسب للعرض فقط ولا يُفرض (لا تكلفة، لا جوع) | يُفرض: أموال، ماء، غذاء، طاقة، استقرار |
| الحفظ | خانة الحفظ القديمة كما هي | خانة منفصلة للتقدم + خانة لمحاولة المرحلة الجارية |

العالم الحر **لا يُمَس** عند دخول الحملة ولا عند الخروج منها، وإعدادات الرسوميات مشتركة وثابتة بين الوضعين.

## الأهداف والنجوم

الأهداف تُقرأ من بيانات المحاكاة الحقيقية كل 3 دقائق من وقت اللعبة (عدد المنازل، السكان، الماء المخزّن في الخزانات، الغذاء، الطاقة، الأموال، الاستقرار، البقاء في وجه عاصفة...) ولا يوجد زر "إنهاء". ★ إكمال المرحلة، ★★ ضمن زمن محدد، ★★★ بزمن أقصر مع استقرار كافٍ وإنجاز الأهداف الإضافية. ويمكنك **إعادة اللعب** أو **المحاولة من جديد** أو الانتقال للتالية من شاشة النتيجة. تُحفظ أفضل نتيجة.

## قواعد الاقتصاد (الحملة فقط)

- **الماء:** مجموع ما في الخزانات؛ كل ساكن يستهلك. **الغذاء:** من المزارع، ويتأثر بالري (ممتاز/جيد/لا يوجد) وبالفيضان. **الطاقة:** شمسية (تتبع الشمس والغيوم) ورياح؛ يقابلها طلب يتغير مع الوقت.
- **الأموال:** ضرائب + إنتاج المصانع − تكلفة التشغيل. **الاستقرار:** مؤشر ناعم من كفاية الماء/الغذاء/الطاقة والفيضانات؛ إن انهار أو غادر السكان كلهم فشلت المرحلة.
- **الأحداث:** أمطار، عواصف، جفاف، مع تحذير مسبق.

## الرسوميات والأداء (ملخص)

- تدرّج التفاصيل حسب المسافة (LOD) لكل نموذج GLB: تُولَّد تلقائيًا مستويات متوسطة ومنخفضة للنماذج التي لا تملك مستويات.
- إخفاء حقيقي للنباتات خارج مسافة الرسم وخارج مجال رؤية الكاميرا (لا تُرسل أصلًا للـ GPU)؛ الأشجار الملقية للظلال لا تُخفى بحقل الرؤية حتى لا تختفي ظلالها.
- دقة ديناميكية بخطوات 5% وبحد أدنى، وAuto Graphics تتصرف بحذر.
- على الهواتف: لا تُقترح أبدًا Ultra، وHigh فقط للأجهزة القوية، والأجهزة الضعيفة تبدأ على Low.
- التفاصيل والأرقام: `GRAPHICS.md` و `REPORT_CAMPAIGN.md`.
